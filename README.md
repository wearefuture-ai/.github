# .github

Domyślne szablony issue i pull requestów dla repozytoriów organizacji WeAreFuture. GitHub używa ich w każdym repo, które nie ma własnych.

- `.github/pull_request_template.md`: opis zmiany, sposób sprawdzenia, ryzyko i wycofanie.
- `.github/ISSUE_TEMPLATE/`: zadanie, błąd, zlecenie dla Loop Factory.

Szablony ustawiają etykiety `feature`, `bug` i `loop-factory`. GitHub dodaje etykietę tylko wtedy, gdy istnieje ona w repozytorium. Proces pracy z agentami (AGENTS.md, walidacja, workflow Loop Factory, taksonomia etykiet: stan, kategoria, priorytet, ryzyko) wnosi do repo szablon `waf-sdlc`.

Repo jest publiczne, bo GitHub wymaga tego dla domyślnych szablonów. Nie wpisuj tu nazw klientów, danych ani szczegółów infrastruktury.
